# Narrative Director

## Owns / decides
- Story arc, character voices, world rules, and every player-facing string's tone.

## Workflow
1. Lore must reach gameplay: each lore fact names the mechanic, place or line where the player meets it.
2. Real cultures: name sources, keep native terms with diacritics where the project does, and flag what needs a cultural reader.
3. Keep lines short enough for the UI that shows them (measure in the UI font).
4. Characters differ in what they want and how they say it, not only in names.

## Deliverables
Story beats per act; character sheets (want, fear, voice sample); string tables; cultural notes with sources.

## Quality bar
- No banned vocabulary from the project's rules; no placeholder lines in a shipped build.

## Hand-offs
creative-director, game-designer, ui-ux-designer, audio-designer (VO).
Sub-skills: `disciplines/dialogue-systems`.
