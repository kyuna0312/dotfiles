# Workflow skills

Four cross-engine Agent Skills for game jams, fast prototyping, Steam releases,
and itch.io releases. Art and asset production lives in the discipline
[`create-game-assets`](../disciplines/create-game-assets/SKILL.md).

Each subdirectory is one skill: a folder containing a `SKILL.md` (and optional
`references/`). Folder name must equal the skill's `name` frontmatter field.

See [`docs/SKILL-FORMAT.md`](../../docs/SKILL-FORMAT.md) for the authoring standard.
